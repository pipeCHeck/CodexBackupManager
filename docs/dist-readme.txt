Codex Backup Manager 0.1.2
==========================

OpenAI Codex 로컬 프로젝트/대화 데이터를 조회, 선택, 내보내기(.codexbackup), 다른 PC로
불러오기/복원하는 Windows 데스크톱 프로그램입니다.

실행 방법
---------
이 폴더 전체가 하나의 프로그램입니다 — CodexBackupManager.exe만 따로 빼서 다른 위치로 옮기지
마십시오. 같은 폴더 안의 DLL/런타임 파일들이 있어야 정상적으로 실행됩니다. 이 폴더를 통째로
원하는 위치(바탕화면, Program Files 등)에 두고 그 안의 CodexBackupManager.exe를 더블클릭하면
바로 실행됩니다. 별도로 .NET 런타임을 설치할 필요가 없습니다(self-contained 배포 — 이 폴더
안에 필요한 런타임 파일이 전부 포함되어 있습니다). 처음 실행 시 Windows SmartScreen이 "인식할
수 없는 앱입니다" 경고를 띄울 수 있습니다 — [추가 정보] -> [실행]으로 진행할 수 있습니다(이
배포판은 code-signing이 되어 있지 않습니다, 아래 알려진 제한 참고).

기본 흐름
---------
1. 프로그램을 실행하면 Codex Home(.codex 폴더)을 자동으로 찾습니다. 못 찾으면 [폴더 선택]으로
   직접 지정할 수 있습니다.
2. 프로젝트/대화 목록에서 내보낼 항목을 선택하고 [내보내기]를 누르면 .codexbackup 파일이
   만들어집니다.
3. 다른 PC에서 이 프로그램을 실행하고 [백업 불러오기]로 .codexbackup 파일을 선택하면 내용을
   미리 볼 수 있습니다(아직 아무것도 적용하지 않습니다).
4. 미리보기를 확인한 뒤 [적용]을 누르면 실제로 Codex에 반영됩니다 — 적용 전 반드시 Codex를
   완전히 종료해야 합니다. 적용 직전에 현재 상태의 복구용 Snapshot이 자동으로 만들어지고,
   중간에 실패하면 자동으로 이전 상태로 복원됩니다.

Snapshot(복구용 백업)에 대해
----------------------------
- [적용]을 누를 때마다 그 순간의 상태가 Snapshot으로 자동 저장됩니다
  (%LOCALAPPDATA%\CodexBackupManager\Snapshots\).
- 이 Snapshot은 적용 실패/크래시 복구에 사용됩니다.
- 이번 버전은 완료된 Snapshot을 자동으로 지우지 않습니다 — 대형 대화를 여러 번 적용하면
  Snapshot 폴더가 커질 수 있습니다. 필요하면 충분히 확인한 뒤 사용자가 직접 정리하십시오.
- "완료되지 못한 이전 적용(Applying)" 또는 손상된 상태로 표시된 Snapshot은 프로그램이 [이전
  상태로 복구]를 안내하기 전까지 직접 지우지 마십시오 — 그 Snapshot이 유일한 복구 수단입니다.

알려진 제한 사항
----------------
- Windows 10/11 x64 전용입니다.
- [적용]은 Codex를 완전히 종료한 뒤에만 진행됩니다(실행 중이면 안내와 함께 거부됩니다).
- 서로 다른 두 PC에서 각각 앞서간 대화(Diverged)의 자동 병합/교체/복사본 가져오기는 아직
  지원하지 않습니다 — 이런 대화는 적용 전체가 안전하게 차단됩니다.
- 압축된 rollout(.jsonl.zst) 파일의 갱신(Update)은 지원하지 않습니다(새로 만드는 것은 됩니다).
- local_image를 제외한 일부 첨부(attachment)의 실제 파일은 백업에 포함/복원되지 않습니다.
- 로컬에 아직 없는 새 프로젝트를 자동으로 만들지는 않습니다.
- Codex Desktop 앱 사이드바에 프로젝트별로 정확히 묶여 보이는지는 아직 별도로 검증하지
  못했습니다(Core/CLI 기준 데이터는 정확합니다).
- 복원 중 잠금(다른 프로그램 인스턴스가 같은 Codex Home을 동시에 처리하지 못하게 막는 장치)은
  같은 Windows 로그인 세션 범위에서만 유효합니다.
- Snapshot은 자동으로 삭제되지 않습니다(위 안내 참고).
- 이 배포판은 code-signing이 되어 있지 않아 Windows SmartScreen 경고가 뜰 수 있습니다.

문제가 발생하면
----------------
프로그램은 %APPDATA%\CodexBackupManager\logs\ 에 로그를 남깁니다(대화 원문은 기록하지
않습니다). 문제를 재현할 수 있으면 이 로그와 함께 보고해 주십시오.
