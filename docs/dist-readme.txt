Codex Backup Manager 0.2.5
==========================

OpenAI Codex의 프로젝트와 대화를 골라 백업 파일(.codexbackup) 하나로 내보내고, 다른 PC에서
가져와 다시 쓸 수 있게 하는 Windows 프로그램입니다.

실행 방법
---------
이 폴더 전체가 하나의 프로그램입니다. CodexBackupManager.exe만 따로 빼서 옮기지 마십시오.
폴더를 통째로 원하는 위치에 두고 그 안의 CodexBackupManager.exe를 실행하면 됩니다.
.NET을 따로 설치할 필요가 없습니다.

처음 실행할 때 Windows SmartScreen이 "인식할 수 없는 앱입니다" 경고를 띄울 수 있습니다.
[추가 정보] -> [실행]으로 진행할 수 있습니다(이 배포판에는 코드 서명이 없습니다).

사용 순서
---------
[이 PC에서 내보내기]
1. 프로그램을 실행하면 Codex 폴더(.codex)를 자동으로 찾습니다. 못 찾으면
   [Codex 폴더 선택]으로 직접 지정합니다.
2. 목록에서 내보낼 프로젝트나 대화를 체크하고 [백업 내보내기]를 누릅니다. 목록 위 검색칸으로
   대화 제목이나 프로젝트 이름을 찾을 수 있습니다(검색해도 체크한 대화는 그대로입니다).
3. 완료 창에 다른 PC로 따로 옮겨야 할 작업 폴더 목록이 나옵니다. 필요하면
   [목록을 텍스트 파일로 저장…]으로 저장해 두십시오.

[다른 PC에서 가져오기]
4. 가져오기 전에 Codex를 종료하십시오. Codex가 실행 중이면 가져오기 화면이 종료를
   기다립니다.
5. [백업 가져오기]로 백업 파일을 엽니다. 아직 아무것도 바뀌지 않습니다.
6. 가져올 대화를 체크합니다. 오른쪽에서 대화 내용을 미리 읽을 수 있고, 위쪽 검색칸으로
   대화 제목이나 프로젝트 이름을 찾을 수 있습니다.
7. 프로젝트마다 "작업 폴더"를 정합니다.
   - Codex에 등록된 폴더면 그 프로젝트에 연결합니다.
   - 등록되지 않은 폴더면 그 폴더로 Codex 프로젝트를 새로 만듭니다(Codex 사이드바에도
     표시됩니다). 원하지 않으면 "새 프로젝트를 만들지 않고 기타 대화로 가져오기"를 고릅니다.
   - 쓸 폴더가 아직 없으면 [새 폴더 만들기]로 빈 폴더를 만들어 지정할 수 있습니다.
   - 백업의 "기타 대화"는 프로젝트 없는 채팅으로 들어갑니다.
8. 아래쪽 "대화 N개 가져오기"를 누르고, 확인 창에서 내용을 확인한 뒤 적용합니다.
9. Codex를 실행해 가져온 대화를 확인합니다.

백업에 들어 있는 것
-------------------
- 백업에는 Codex 대화 데이터만 들어 있습니다.
- 작업 폴더 안의 실제 파일(소스 코드, 프로젝트 파일 등)은 백업에 들어 있지 않습니다.
  작업 폴더는 Git이나 다른 방법으로 따로 옮기십시오.

되돌리기
--------
- 메인 화면의 [가져오기 기록]에서 지금까지 한 가져오기를 볼 수 있습니다.
- 성공한 가져오기는 결과 화면의 [이 가져오기 되돌리기] 또는 기록 창의 [되돌리기]로
  되돌릴 수 있습니다. 새로 가져온 대화를 지우고, 옮기거나 이어받은 대화는 가져오기 전
  상태로 돌리고, 새로 만든 프로젝트를 지웁니다. 되돌리기도 Codex를 종료한 상태에서 합니다.
- 다음 경우에는 되돌리지 않고 이유를 보여 줍니다.
  - 가져온 대화를 Codex에서 이미 열어 봤거나 이어서 쓴 경우
  - 0.1.x 버전으로 한 가져오기
- 새로 만든 프로젝트를 Codex에서 쓰고 있으면(다른 대화가 들어 있거나 고정한 경우 등)
  대화만 되돌리고 프로젝트는 남겨 둡니다.
- 일부 대화만 골라 되돌리는 기능은 없습니다.

복구 지점(Snapshot)
-------------------
- 가져오기, 되돌리기, 사이드바 표시를 할 때마다 바꾸기 직전 상태를 복구 지점으로 먼저
  저장합니다(%LOCALAPPDATA%\CodexBackupManager\Snapshots\). 중간에 실패하면 이것으로
  자동으로 원래대로 돌립니다. 되돌리기에도 이 기록이 필요합니다.
- 기록은 자동으로 지우지 않습니다. [가져오기 기록] 창에서 [선택 삭제]나
  [30일 지난 기록 정리]로 지울 수 있습니다(확인을 받은 뒤에만 지웁니다).
- 폴더를 직접 지우지 마십시오. 특히 "완료되지 못한 이전 작업"으로 안내된 기록은 프로그램이
  [이전 상태로 복구]를 마칠 때까지 남겨 두어야 합니다.

알려진 제한 사항
----------------
- Windows 10/11 x64 전용입니다.
- 두 PC에서 각각 이어서 쓴 대화(충돌)는 가져올 수 없습니다. 그런 대화만 빼고 나머지는
  가져올 수 있습니다.
- 압축된 대화 파일(.jsonl.zst)은 이어받을 수 없습니다(새로 가져오는 것은 됩니다).
- 붙여넣은 이미지(local_image)를 제외한 첨부 파일은 백업에 들어가지 않습니다.
- Codex 데스크톱 앱이 위치를 따로 기록한 대화는 프로젝트로 옮기지 않습니다.
- 백업의 "기타 대화"를 이 PC에서 프로젝트로 묶어 가져오는 기능은 없습니다.
- 동시 실행 잠금은 같은 Windows 로그인 세션 안에서만 유효합니다.

이 프로그램이 Codex에 쓰는 곳
------------------------------
가져오기·되돌리기·사이드바 표시 때만, 복구 지점을 만든 뒤에 씁니다.
- 대화 파일(sessions 폴더의 rollout 파일)
- Codex 상태 DB(state_*.sqlite): 대화 행, 대화의 프로젝트·작업 폴더, 새 프로젝트 행
- Codex 데스크톱 앱 상태 파일(.codex-global-state.json): 사이드바에 보일 프로젝트 목록
목록 보기, 대화 보기, 내보내기는 Codex 데이터를 바꾸지 않습니다.

문제가 발생하면
----------------
프로그램은 %APPDATA%\CodexBackupManager\logs\ 에 로그를 남깁니다(대화 원문은 기록하지
않습니다). 문제를 재현할 수 있으면 이 로그와 함께 알려 주십시오.
