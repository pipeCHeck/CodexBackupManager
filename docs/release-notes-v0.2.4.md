# Codex Backup Manager 0.2.4

v0.2.4 릴리스 노트입니다. 이 문서는 GitHub Release 본문으로 그대로 쓸 수 있도록 작성했습니다 —
실제 Tag/Release 업로드는 사용자가 이 작업 트리를 검토·커밋한 뒤 직접 진행합니다.

## 이게 무엇인가요

OpenAI Codex(CLI/Desktop)의 로컬 프로젝트·대화를 골라 `.codexbackup` 파일 하나로 내보내고, 다른
PC에서 가져와 다시 쓸 수 있게 하는 Windows 데스크톱 프로그램입니다. 설치가 필요 없는 **폴더형**
배포입니다 — 압축을 푼 폴더를 통째로 두고 그 안의 `CodexBackupManager.exe`를 실행하면 됩니다
(.NET 런타임을 따로 설치할 필요가 없습니다).

0.2.4는 **가져오기를 처음부터 다시 만든 버전**입니다. 가져올 대화를 직접 고르고, 대화가 들어갈
작업 폴더(프로젝트)를 지정하고, 성공한 가져오기를 되돌릴 수 있습니다.

## 사용자가 알아야 할 변화

### 새 가져오기 화면

- 메인 목록과 같은 **프로젝트 → 대화 트리와 체크박스**로 가져올 대화를 고릅니다.
  [새 대화만] / [전체 선택] / [모두 해제]로 한 번에 고를 수 있습니다.
- 대화마다 상태 배지(새 대화, 이어받기, 이미 있음, 이 PC가 최신, 충돌 등)와 적용 후 들어갈 위치를
  보여 줍니다. 가져올 수 없는 대화는 이유를 함께 보여 주고, 그 대화만 빼고 나머지는 가져올 수
  있습니다.
- 오른쪽에서 **백업 속 대화 내용을 미리 읽을 수** 있습니다(아직 아무것도 가져오지 않은 상태).
- **검색**: 대화 제목과 프로젝트 이름으로 찾습니다. 검색은 보이는 항목만 바꾸고 고른 상태는
  그대로 둡니다.
- 아래쪽 요약과 버튼(예: "대화 3개 가져오기")이 고른 내용을 바로 반영합니다. 적용 전에 확인
  창에서 새로 가져올 대화 수, 새로 만들 프로젝트 등을 한 번 더 보여 줍니다.

### 작업 폴더 지정

백업의 프로젝트마다 "이 PC에서 쓸 작업 폴더"를 지정합니다.

- **Codex에 이미 등록된 프로젝트 폴더**면 그 프로젝트에 연결합니다. 원본 폴더가 이 PC에서도 Codex
  프로젝트로 등록돼 있으면 처음부터 그 프로젝트가 골라져 있습니다.
- **Codex에 등록되지 않은 폴더**면 그 폴더로 **Codex 프로젝트를 자동으로 만들고** 대화를 그 안에
  넣습니다. 새 프로젝트는 Codex 데스크톱 앱 **사이드바에도 표시**됩니다. 이름은 바꿀 수 있고,
  원하지 않으면 "새 프로젝트를 만들지 않고 기타 대화로 가져오기"를 고르면 됩니다.
- **[새 폴더 만들기]**: 원본 폴더가 이 PC에 없을 때처럼 쓸 폴더가 아직 없으면, "새 폴더 위치" 아래에
  프로젝트 이름으로 빈 폴더를 만들고 바로 작업 폴더로 지정합니다. 위치는 [변경…]으로 바꿀 수
  있습니다.
- 백업의 **"기타 대화"**(프로젝트 없는 대화)는 이 PC에서도 **프로젝트 없는 채팅**으로 가져옵니다.

### 이미 있는 대화를 프로젝트로 옮기기

- 이 PC에 이미 있는 대화가 "기타 대화"에 들어가 있으면, 가져오기 화면에서 그 대화를 지정한 작업
  폴더의 프로젝트로 **옮길 수** 있습니다(내용은 그대로 두고 소속만 바꿉니다). 기본은 꺼져 있습니다.
- Codex 데스크톱 앱이 대화의 위치를 따로 기록해 둔 대화는 옮기지 않습니다(이유를 표시합니다).
- 이미 그 프로젝트에 들어 있는 대화에는 옮기기 항목이 나오지 않습니다.

### 사이드바 보정

- 0.2 개발 중에 만든 프로젝트처럼 이 앱이 만들었지만 Codex 사이드바에 보이지 않는 프로젝트가
  있으면, 메인 화면에 안내와 **[사이드바에 표시]** 버튼이 나옵니다. 누르면 Codex 데스크톱 앱
  상태 파일에 그 프로젝트를 추가합니다(Snapshot을 먼저 만듭니다).

### 메인 화면

- 메인 목록에도 **검색 칸**이 생겼습니다(대화 제목 또는 프로젝트 이름). 검색은 보이는 항목만 바꾸고,
  체크한 대화는 목록에 안 보여도 그대로 내보내기에 들어갑니다(검색 중에는 그 개수를 함께 보여 줍니다).
- 처음 쓰는 분을 위한 **사용 방법 안내**, 버튼 설명(툴팁, 버튼이 꺼진 이유 포함)을 넣었습니다.
- 기본 화면은 프로젝트·대화 수와 Codex 버전만 보여 주고, 자세한 진단 정보는 [상세 정보]에 있습니다.
- 창을 줄였을 때 대화 내용이 잘리거나 하단 버튼이 가려지던 문제를 고쳤습니다.
- 목록에서 줄을 고른 뒤 **Space**로 체크할 수 있습니다.
- 프로그램 **아이콘**을 새로 넣었습니다(실행 파일, 작업 표시줄, 창 제목).
- 내보내기 완료 창에 경고가 있으면 그 내용(예: 찾지 못한 첨부 이미지 수)을 보여 주고, 목록 txt에도 적습니다.

### 내보내기 완료 안내

- 내보내기가 끝나면 완료 창에서 백업 파일, 담긴 프로젝트·대화 수, 그리고 **다른 PC로 따로 옮겨야
  할 작업 폴더** 목록을 보여 줍니다. 이 목록은 **텍스트 파일(txt)로 저장**할 수 있습니다
  ([목록을 텍스트 파일로 저장…]).

### 가져오기 기록 · 되돌리기 · Snapshot 정리

- 메인 화면 **[가져오기 기록]**에서 이 Codex 폴더에 대한 가져오기 기록을 최신순으로 봅니다(날짜,
  백업 파일 이름, 결과, 가져온 개수, 되돌릴 수 있는지).
- **성공한 가져오기를 되돌릴 수 있습니다** — 결과 화면의 [이 가져오기 되돌리기] 또는 기록 창의
  [되돌리기]. 그 가져오기가 쓴 것만 거꾸로 되돌립니다: 새로 가져온 대화를 지우고, 이어받은 대화는
  가져오기 전 길이로 돌리고, 옮긴 대화는 원래 위치로 돌리고, 새로 만든 프로젝트를 지웁니다.
  되돌리기 전에도 Snapshot을 만들고, 실패하면 원래대로 둡니다.
- 다음 경우에는 되돌리지 않고 이유를 보여 줍니다.
  - 가져온 뒤 **Codex에서 열어 본 대화**나 이어서 쓴 대화가 있을 때(그 기록 전체를 되돌리지
    않습니다)
  - 새로 만든 프로젝트를 Codex에서 쓰고 있을 때(다른 대화가 들어 있거나, 고정했거나, 사이드바
    항목을 바꾼 경우) — 대화는 되돌리고 **프로젝트는 남겨 둡니다**
- **Snapshot 정리**: 기록 창에서 고른 기록을 지우거나([선택 삭제]), 30일이 지난 되돌릴 수 없는
  기록을 한꺼번에 지울 수 있습니다([30일 지난 기록 정리]). 항상 확인을 받은 뒤에만 지우고,
  자동으로 지우지 않습니다. 진행 중이거나 완료되지 못한 기록은 지우지 않습니다.

### Codex 실행 정책

- **가져오기(분석·미리보기·적용)와 되돌리기는 Codex를 종료한 상태에서 시작합니다.** Codex가
  실행 중이면 가져오기 화면이 종료를 기다리는 안내를 보여 줍니다.
- **목록 보기, 대화 내용 보기, 내보내기는 Codex가 실행 중이어도 됩니다.**

## 이 앱이 Codex 데이터에 새로 쓰는 곳

0.1.x는 rollout 파일과 `threads` 행만 썼습니다. 0.2.4는 아래를 **새로** 씁니다. 모든 쓰기는
Codex 종료 확인 → Snapshot → 쓰기 → 결과 검증 → 실패 시 자동 Rollback 안에서만 일어납니다.

- **state DB(`state_*.sqlite`)**
  - 새 프로젝트를 만들 때 `projects` / `project_roots` / `project_idempotency_keys` 행
  - 대화의 소속(`threads.project_id`)과 작업 폴더(`threads.cwd`) — 프로젝트에 넣거나 옮길 때
  - 되돌리기 때는 위 행을 지우거나 이전 값으로 되돌립니다.
- **Codex 데스크톱 앱 상태 파일(`.codex-global-state.json`)**
  - 사이드바 표시를 위한 `local-projects`, `project-order`, 레거시 프로젝트 ID → DB 프로젝트 매핑
  - 이 앱이 추가한 항목만 다루고, 다른 내용은 바이트 그대로 둡니다. 파일 형식을 확인할 수 없으면
    쓰지 않습니다.

## 백업 형식

- 백업 형식(Backup Format V1)은 **바뀌지 않았습니다.** 0.1.x에서 만든 백업도 그대로 가져올 수
  있고, 0.2.4에서 만든 백업도 같은 형식입니다.
- 백업에는 Codex 대화 데이터만 들어 있습니다. **작업 폴더 안의 실제 파일(소스 코드 등)은 들어 있지
  않습니다.**

## 사용법

1. 압축을 풀어 나온 `CodexBackupManager-v0.2.4-win-x64` 폴더 안의 `CodexBackupManager.exe`를
   실행합니다(폴더 안의 다른 파일은 그대로 두어야 합니다).
2. Codex 폴더를 자동으로 찾지 못하면 [Codex 폴더 선택]으로 직접 지정합니다.
3. 내보낼 프로젝트나 대화를 고르고 [백업 내보내기]로 `.codexbackup` 파일을 만듭니다.
4. 다른 PC에서 **Codex를 종료한 뒤** 이 프로그램을 실행하고 [백업 가져오기]로 그 파일을 엽니다.
5. 가져올 대화를 고르고, 프로젝트마다 작업 폴더를 지정하거나 [새 폴더 만들기]를 누릅니다.
6. "대화 N개 가져오기"를 누르고 확인 창에서 내용을 확인한 뒤 적용합니다.
7. Codex를 실행해 가져온 대화를 확인합니다. 잘못 가져왔으면 Codex에서 열어 보기 전에
   [가져오기 기록]에서 되돌릴 수 있습니다.

자세한 안내는 배포 폴더의 `README.txt`(`docs/dist-readme.txt`)를 참고하세요.

## 알려진 제한 사항

- **0.1.x 버전으로 한 가져오기는 되돌릴 수 없습니다**(기록 창에 "이전 버전에서 만들어져
  되돌리기를 지원하지 않습니다"로 보입니다). 사이드바 보정 기록도 되돌리지 않습니다.
- **부분 되돌리기는 없습니다.** 되돌릴 수 없는 대화가 하나라도 있으면 그 가져오기 전체를 되돌리지
  않습니다.
- 백업의 "기타 대화"를 이 PC에서 프로젝트로 묶어 가져오는 기능은 제공하지 않습니다(프로젝트 없는
  채팅으로 들어갑니다).
- Codex 데스크톱 앱이 위치를 따로 기록한 대화는 프로젝트로 옮기지 않습니다.
- 0.2 개발 중 "기타 대화"를 프로젝트로 만들어 가져온 경우, 오래된 채팅 일부가 Codex 사이드바에
  보이지 않은 사례가 있었습니다. 원인은 아직 확정하지 못했습니다.
- 두 PC에서 각각 이어서 쓴 대화(충돌)의 자동 병합, 백업으로 기존 대화 내용 교체, 압축
  rollout(`.jsonl.zst`) 이어받기는 지원하지 않습니다. 이런 대화만 빼고 나머지는 가져올 수 있습니다.
- `local_image`를 제외한 첨부 파일은 백업에 포함되지 않습니다.
- Windows 10/11 x64 전용입니다. 동시 실행 잠금은 같은 Windows 로그인 세션 안에서만 유효합니다.
- 이 배포판은 code-signing되지 않았습니다 — 첫 실행 시 Windows SmartScreen이 경고를 띄울 수
  있습니다([추가 정보] → [실행]으로 진행 가능).

## SHA-256 확인 방법

배포 ZIP과 같은 폴더의 `SHA256SUMS.txt`에 해시가 있습니다. PowerShell에서 다음처럼 비교하세요.

```powershell
Get-FileHash .\CodexBackupManager-v0.2.4-win-x64.zip -Algorithm SHA256
```

출력된 해시가 `SHA256SUMS.txt`에 적힌 값과 정확히 같아야 합니다.
