### 9_6-01 "내보내기 완료" 대화상자
- 내보내기 **성공 직후 한 번** 띄운다. 실패·취소 때는 띄우지 않고 기존 상태 문구만 둔다.
- 내용(설계 §6 "9_6" 그대로)
  - 요약: 백업 파일 이름, 크기, 대화 N개 · 프로젝트 M개
  - 강조 안내: "백업 파일에는 Codex 대화 기록만 들어 있습니다. 작업 폴더의 파일(소스 코드, 문서, 에셋 등)은 들어 있지 않습니다. 다른 PC에서 이어서 작업하려면 아래 작업 폴더를 Git, USB, 클라우드 드라이브 등으로 따로 옮겨 주세요."
  - 작업 폴더 목록: 프로젝트 이름 → 루트 폴더(여러 개면 모두). 이 PC에 없는 폴더는 "(이 PC에 없음)"을 붙인다.
    "기타 대화"는 대화들의 작업 폴더(cwd)를 중복 없이 보여 준다. 표시 경로에는 `\\?\`를 붙이지 않는다(기존 DisplayPath 규칙).
  - 목록이 길면 그 영역만 스크롤한다.
  - 팁: "다른 PC에서 가져올 때, 옮긴 폴더를 작업 폴더로 지정하면 그 프로젝트에 연결됩니다."
  - 버튼: [목록을 텍스트 파일로 저장…] [닫기]. 버튼 아래 작은 글씨: "텍스트 파일에는 대화 제목과 폴더 경로가 그대로 적힙니다."
- 앱의 다크 테마 리소스를 쓰고, 좁은 폭에서도 겹치지 않으며, 키보드로 조작할 수 있게 한다.
- 다시 보지 않기 옵션은 만들지 않는다(사용자가 요청하지 않음).

### 9_6-02 [목록을 텍스트 파일로 저장…]
- 저장 대화상자의 기본 위치는 백업과 같은 폴더, 기본 이름은 `<백업 파일 이름(확장자 제외)>.txt`
- UTF-8 BOM, CRLF(메모장 호환). 형식은 설계 §6 "9_6" 예시를 따른다.
  - 머리: 만든 시각(이 PC 시간대 표기), 백업 파일 이름(크기), 대화·프로젝트·기타 대화 개수, 작업 폴더 안내
  - 프로젝트별 블록: 이름, 작업 폴더(들), 대화 목록(제목, 만든 날, 마지막 수정)
  - 마지막에 "[기타 대화]" 블록: 대화 제목과 각 작업 폴더
- 텍스트 파일에는 "이 PC에 없음"을 적지 않는다(다른 PC에서 읽을 때 오해). 대화상자에서만 보여 준다.
- 저장하면 대화상자 안에 "저장했습니다: <파일 이름>"을 표시한다. 실패하면 사유(예외 형식 이름)를 표시한다.
- 이 파일은 백업 파일 안에 넣지 않는다(Backup Format V1 FROZEN). 가져오기도 이 파일을 읽지 않는다.

### 9_6-03 목록 생성은 Backup 층 순수 함수
- 입력: 이번 내보내기의 ExportPlan/Manifest + 백업 파일 정보(이름, 크기, 만든 시각), 시간대
- 출력: 대화상자용 모델(프로젝트 → 폴더 목록, 기타 대화 폴더 목록)과 텍스트 문자열
- 폴더가 이 PC에 있는지는 App 층에서 확인한다(Directory.Exists). 순수 함수는 파일 시스템을 보지 않는다.
- 값은 Manifest에 실제로 있는 것만 쓴다. 없는 값을 만들어 넣지 않는다(CLAUDE.md §12 "확인할 수 없는 값은 억지로 만들지 않는다"). 비어 있으면 그 줄을 생략한다.

### 9_2-37 Failed 화면의 [다시 분석]

## 3. 안전 규칙과 환경
- 실제 C:\Users\User\.codex에는 절대 쓰지 않는다. 작업 전후 4개 파일 SHA-256을 비교해 보고한다(state_5.sqlite, session_index.jsonl, .codex-global-state.json, config.toml).
  사용자가 Codex를 쓰는 중이면 값이 바뀔 수 있다. 그때는 열지 않았다는 사실과 수정 시각만 보고한다.
- 테스트는 temp 폴더만 쓴다. 사용자 문서 폴더에 파일을 만들지 않는다.
- 앱을 띄워 보더라도 [가져오기]·[새 폴더 만들기]·[사이드바에 표시]는 누르지 않는다. 내보내기를 해 볼 때는 결과 파일을 스크래치 폴더에만 저장한다.
- 테스트에서 MainViewModel의 [새로고침] 같은 자동 탐지가 실제 .codex를 읽지 않도록 harness 사본으로 연결한다(9_5a-1에서 한 번 있었던 일).
- 로그에 경로·제목·이름·파일 이름을 남기지 않는다(개수와 결과만).
- 사용자가 실험 빌드(artifacts\test-9_0C)나 개발 빌드 앱을 실행 중일 수 있다.
  - 그 프로세스를 종료하지 않는다. artifacts 폴더는 건드리지 않는다.
  - 빌드가 잠기면 저장소를 bin/obj/.git 없이 스크래치로 복사해 빌드·테스트하고 그렇게 보고한다.
- 복제본을 CODEX_HOME으로 codex.exe 실행 금지.
